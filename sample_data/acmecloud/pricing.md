# AcmeCloud Plans and Billing

## Starter
Starter costs $19 per user per month when billed monthly. It includes 50 GB of workspace storage, community support, and 10,000 API requests per month. Starter does not include SAML SSO or private networking.

## Business
Business costs $49 per user per month when billed monthly, or $39 per user per month on an annual commitment. It includes 500 GB of workspace storage, SAML SSO, priority support, 100,000 API requests per month, and 90-day audit log retention.

## Enterprise
Enterprise pricing is contract-based. It includes SCIM provisioning, 365-day audit log retention, private networking, selectable data residency, audit log streaming, and negotiated API quotas. Customer-managed encryption keys are available in supported regions.

## Overage and cancellation
API requests above a contracted quota are charged only when overage billing is enabled for the workspace. Annual Business subscriptions can be reduced at the next renewal date but are not prorated for mid-term seat reductions. Monthly Starter subscriptions can be canceled at the end of the current billing month.
